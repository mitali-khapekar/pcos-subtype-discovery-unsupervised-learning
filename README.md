# PCOS Subtype Discovery using Unsupervised Learning

This project explores subtype identification in PCOS patients using unsupervised machine learning techniques.

## Research Paper
Subtype Discovery in PCOS Patients: An Unsupervised Learning and Explainability Approach  
Published in Journal of Advanced Multidisciplinary Research Studies and Development (JAMRSD), 2026.

## Dataset
The datasets include clinical and patient attributes related to PCOS diagnosis and symptoms.

Files:
- pcos_clinical_data.csv
- pcos_patient_records.csv

## Methodology
The study applied the following techniques:

- Data preprocessing and cleaning
- Feature standardization
- Principal Component Analysis (PCA)
- Clustering Algorithms:
  - K-Means
  - Gaussian Mixture Models
  - Agglomerative Clustering
- Silhouette Score evaluation
- Cluster visualization

## Key Findings
Two major PCOS subtypes were identified:

• Lean PCOS  
• Metabolic / Insulin Resistant PCOS
